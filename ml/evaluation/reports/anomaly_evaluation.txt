3. METHODOLOGICAL RIGOR & INTERPRETATION RULES
--------------------------------------------------------------------------------
Rule 1: Anomaly Score != Failure Probability.
  Isolation Forest measures whether a sensor point is 'easy to isolate' via random
  hyperplane cuts. It is an unsupervised outlier detector, not a failure classifier.

Rule 2: Lack of Ground Truth Anomaly Labels.
  In real industrial settings, machine operators experience sensor dropouts, thermal
  drift, and off-nominal load points that are anomalous without failing the machine.
  Therefore, supervised classification metrics (precision/recall on failure labels)
  are mathematically invalid as 'anomaly precision/recall'.
